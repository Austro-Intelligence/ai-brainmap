Privacy Policy — ai-brainmap

Last updated: 29 May 2026

In short: ai-brainmap runs entirely on your own machine. It collects no personal data, contains no telemetry or analytics, and sends nothing to Austro Intelligence. The only case where data can leave your machine is an optional topic-clustering feature you configure yourself — and even then it defaults to a local model.

ai-brainmap is an open-source plugin for Claude Code, published by Austro Intelligence under the MIT license. This policy explains what the plugin does with your data and what this website does when you visit it.

1. Who we are

Austro Intelligence (the “we”/“us”), Austria. Contact: hello@austro-intelligence.at. Project home: github.com/Austro-Intelligence/ai-brainmap.

2. Data the plugin collects about you

None. We operate no servers, accounts, analytics or telemetry. The plugin never transmits your prompts, tool calls, responses or any usage data to us or to any third party we control.

3. How the plugin processes your data locally

To draw the mindmap, the plugin runs a small HTTP server on your own computer, bound to 127.0.0.1:4823 (localhost only — not reachable from the network). On that machine it:

  • receives Claude Code hook events (prompts, tool calls, responses) and holds them in memory;
  • reads the active Claude Code session transcript file to display thinking and assistant text;
  • renders all of this as a graph in your local browser.

This data stays in memory for the running session, is capped by a ring buffer, and is discarded when you stop the server or run /brainmap clear. It is never sent off your machine by the plugin itself.

4. Optional LLM topic clustering

The plugin offers an optional feature that groups nodes into topics using an OpenAI-compatible language model. By default it targets a model on your own machine (localhost:1234, e.g. LM Studio or Ollama), so nothing leaves your computer.

If you change the configured endpoint in ~/.claude/brainmap-llm.json to a remote provider, the labels and summaries of your nodes are sent to that provider to perform the clustering. In that case the data is handled under that provider’s privacy policy, not ours. This is entirely opt-in and under your control; remove the configuration to keep clustering fully offline.

5. This website

This page is hosted on GitHub Pages. We do not add cookies, trackers or analytics to it. As the host, GitHub may log standard technical information such as IP address and browser user-agent; this is governed by the GitHub Privacy Statement.

6. Children

ai-brainmap is a developer tool and is not directed at children under 16.

7. Changes to this policy

We may update this policy as the plugin evolves. The current version is always available at this URL, with the “last updated” date above.

8. Contact
